# 事件

RenderJS 的所有事件都在 `RenderJSEvents` 事件组里，注册方式：

```js
RenderJSEvents.onGuiPreRender(event => {
  // ...
})
```

| 事件 | 触发时机 | 每帧次数 | 回调对象能力 |
|---|---|---|---|
| `onGuiPreRender` | HUD 渲染之前 | 1 | [GUI 绘制](GUI绘制.md) + 2D 变换 + `getWindow()` / `getPartialTick()` |
| `onGuiPostRender` | HUD 渲染之后 | 1 | 同上 |
| `onScreenPreRender` | 任意 Screen 渲染之前 | 打开界面时 1 | GUI 绘制 + 2D 变换 + `getScreen()` / `getMouseX()` / `getMouseY()` |
| `onScreenPostRender` | 任意 Screen 渲染之后 | 打开界面时 1 | 同上 |
| `onLevelRender` | 世界自定义几何提交阶段 | 1 | [世界渲染](世界渲染.md) + 3D 变换 + 相机/关卡状态 |
| `onLivingPreRender` | 每个生物实体渲染之前 | 每个可见实体 1 | [世界渲染](世界渲染.md) + 3D 变换 + 渲染状态/渲染器 |
| `onLivingPostRender` | 每个生物实体渲染之后 | 每个可见实体 1 | 同上 |
| `RegisterItemDecorations` | 客户端启动 / 资源重载时 | 一次性 | 注册物品装饰（见[物品装饰](物品装饰.md)） |
| `registerBlockEntityRender` | 注册方块实体渲染器阶段 / 脚本重载时 | 一次性 | 注册或热替换脚本方块实体渲染器（见[实体与方块实体](实体与方块实体.md)） |

> 26.1.2 起世界渲染只有**一次几何提交**，不再有 `AFTER_ENTITIES` 之类的阶段区分；
> `onLevelRender` 的 `event.getStage()` 固定返回 `"submit"`（对应 `RenderJSLevelRenderStage.SUBMIT`）。

## GUI 事件

```js
RenderJSEvents.onGuiPreRender(event => {
  event.fill(8, 8, 160, 30, 0xAA000000)
  event.drawString(Text.ofString('HUD'), 12, 12, 0xFFFFFFFF)
})

RenderJSEvents.onScreenPreRender(event => {
  // 只在非 HUD 的界面（背包、箱子、自定义界面）触发
  event.fill(2, 2, 10, 10, 0xFF00FF00)
})
```

- 事件对象同时具备 [GUI 绘制](GUI绘制.md) 和 2D 变换能力；
- GUI 事件里抛出的异常会被 RenderJS 捕获并把渲染挂起（直到下次脚本重载），避免刷屏崩溃；
- 需要全局暂停渲染可设置 `RenderJS.CAN_RENDER` 为 false（Java 侧开关，脚本一般不直接改）。

## 世界事件

```js
RenderJSEvents.onLevelRender(event => {
  const poseStack = event.getPoseStack()
  event.pushPose()
  event.transformerCamera(poseStack)              // 世界坐标 → 相机相对坐标
  event.transformerToBlockPose(poseStack, new BlockPos(0, 64, 0))
  event.renderHitOutline(Blocks.DIAMOND_BLOCK.defaultBlockState(), poseStack)
  event.popPose()
})
```

- 相机相对坐标、渲染顺序与限制见[世界渲染](世界渲染.md)；
- 每个可见生物实体的 `onLivingPreRender/Post` 里同样可以做世界渲染。

## 物品装饰与方块实体

这两个事件只在**注册阶段**触发（不是每帧）：

```js
RenderJSEvents.RegisterItemDecorations(event => {
  event.registerForAllItem(ctx => {
    ctx.fill(ctx.xOffset + 12, ctx.yOffset + 12, ctx.xOffset + 16, ctx.yOffset + 16, 0xFF00FF00)
  })
})
```

```js
RenderJSEvents.registerBlockEntityRender(event => {
  event.registerOrSwap(BlockEntityType.CHEST, ctx => new RenderJSBlockEntityRenderer(ctx))
})
```

细节见[物品装饰](物品装饰.md)与[实体与方块实体](实体与方块实体.md)。

## 注意事项

1. **渲染事件都在客户端**；服务端脚本里注册无效。
2. **不要在渲染事件里做重活**：回调每帧执行，遍历/递归/大量字符串拼接会直接掉帧。
3. **不要跨帧保存事件对象**：事件对象（`event`、`ctx`）是复用的，只在本次回调内有效。
4. **不要在事件回调里注册装饰/方块实体**：这两个注册必须发生在注册事件里。
5. 脚本重载（F3 + T）会重新触发注册事件，RenderJS 会先清空旧注册再应用新的。
