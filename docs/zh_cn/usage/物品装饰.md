# 物品装饰

物品装饰会在**物品图标上**再画一层内容，适用于耐久条、数量角标、自定义标记、边框等。

## 注册

```js
RenderJSEvents.RegisterItemDecorations(event => {
  // 只对某个物品生效
  event.register(Items.DIAMOND, ctx => {
    ctx.fill(ctx.xOffset, ctx.yOffset, ctx.xOffset + 16, ctx.yOffset + 1, 0xFFFF0000)
  })

  // 对所有物品生效
  event.registerForAllItem(ctx => {
    if (ctx.itemStack.count > 1) {
      ctx.fill(ctx.xOffset + 12, ctx.yOffset + 12, ctx.xOffset + 16, ctx.yOffset + 16, 0xFF00FF00)
    }
  })
})
```

| 方法 | 说明 |
|---|---|
| `register(item, consumer)` | 给指定物品注册装饰（`item` 是 `Item`，例如 `Items.DIAMOND`） |
| `registerForAllItem(consumer)` | 给所有物品注册装饰 |

每个物品/全局可以注册多个回调，按注册顺序执行。

## 渲染上下文

回调参数 `ctx` 提供：

| 字段/方法 | 说明 |
|---|---|
| `ctx.itemStack` | 当前物品（`ItemStack`） |
| `ctx.font` | 字体（`Font`） |
| `ctx.xOffset` / `ctx.yOffset` | 物品图标在屏幕上的左上角坐标 |
| `ctx.xOffset` / `ctx.yOffset` 之外 | 物品默认是 16×16，装饰一般画在 `ctx.xOffset ~ ctx.xOffset+16` 范围内 |
| 绘制方法 | 同 [GUI 绘制](GUI绘制.md)：`fill` / `hLine` / `vLine` / `drawString` / `drawShadowString` / `drawTexture` / `drawTextureWithSize` / `renderGuiItem` |
| 2D 变换 | `pushPose` / `popPose` / `translate` / `scale` / `rotateDegrees` |

## 示例

### 自定义耐久条

```js
RenderJSEvents.RegisterItemDecorations(event => {
  event.registerForAllItem(ctx => {
    const stack = ctx.itemStack
    if (!stack.isDamageableItem()) return

    const max = stack.maxDamage
    const damage = stack.damageValue
    if (max <= 0 || damage <= 0) return

    const ratio = 1 - damage / max
    const width = Math.round(ratio * 13)
    const color = ratio > 0.5 ? 0xFF00FF00 : (ratio > 0.2 ? 0xFFFFFF00 : 0xFFFF0000)

    // 画在物品底部
    ctx.fill(ctx.xOffset + 2, ctx.yOffset + 13, ctx.xOffset + 13, ctx.yOffset + 15, 0xFF000000)
    ctx.fill(ctx.xOffset + 2, ctx.yOffset + 13, ctx.xOffset + 2 + width, ctx.yOffset + 15, color)
  })
})
```

### 右上角数量角标（自定义）

```js
RenderJSEvents.RegisterItemDecorations(event => {
  event.registerForAllItem(ctx => {
    if (ctx.itemStack.count > 1) {
      ctx.drawShadowString(Text.ofString(ctx.itemStack.count), ctx.xOffset + 9, ctx.yOffset - 2, 0xFFFFD700)
    }
  })
})
```

## 注意

1. **只在 GUI 内的物品上触发**（背包、箱子、合成栏、tooltip 内的物品等），不用于世界里的掉落物；
2. 每个物品每帧都会调用，回调要保持轻量；
3. 脚本/资源重载时 `RegisterItemDecorations` 会重新触发，RenderJS 会先清空旧注册再应用新回调，所以不用手动清理；
4. `register` 的 item 参数是 `Item`，不是 `ItemStack`：用 `Items.DIAMOND` 这类物品常量，或 `Item.of('minecraft:diamond').item`；
5. 全局装饰的实现基于对 `GuiGraphicsExtractor#itemDecorations` 的注入，会叠加在原版数量/耐久条绘制之后。
