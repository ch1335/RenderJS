# 实体与方块实体

## 生物实体事件

`onLivingPreRender` / `onLivingPostRender` 在每个可见生物实体渲染前后触发，事件对象提供：

| 方法 | 说明 |
|---|---|
| `getRenderState()` | 实体的渲染状态（`EntityRenderState`），常用字段：`x` / `y` / `z`、`lightCoords`、`partialTick`、`boundingBoxWidth/Height`、`ageInTicks`、`nameTag` 等 |
| `getRenderer()` | 该实体的渲染器（`LivingEntityRenderer`） |
| `getPartialTick()` | 当前帧 partial tick |
| 世界渲染方法 | 同[世界渲染](世界渲染.md)：`renderSingleBlock` / `renderLevelItem` / `renderHitOutline` / `packLight` 等 |
| 3D 变换 | `pushPose` / `popPose` / `translate` / `scale` / `mulPose` / `rotationDegreesX/Y/Z` |

```js
RenderJSEvents.onLivingPreRender(event => {
  const state = event.getRenderState()
  const poseStack = event.getPoseStack()

  event.pushPose()
  event.transformerCamera(poseStack)
  event.translate(state.x, state.y + state.boundingBoxHeight + 0.4, state.z)
  event.renderLevelItem(Item.of('minecraft:emerald'), poseStack, state.lightCoords)
  event.popPose()
})
```

> 实体渲染是逐实体的，别在这里做与实体无关的全局计算；`Pre` 与 `Post` 的 pose 状态不同，建议总是 `pushPose`/`popPose` 成对使用。

## 方块实体渲染器

`registerBlockEntityRender` 事件用于给方块实体注册**脚本渲染器**：

```js
const BlockEntityType = Java.loadClass('net.minecraft.world.level.block.entity.BlockEntityType')

RenderJSEvents.registerBlockEntityRender(event => {
  event.registerOrSwap(BlockEntityType.CHEST, ctx => {
    const renderer = new RenderJSBlockEntityRenderer(ctx)

    renderer.setCustomRender((r, c) => {
      c.pushPose()
      c.translate(0.5, 0.5, 0.5)                       // 方块中心
      c.renderSingleBlock(Blocks.DIAMOND_BLOCK.defaultBlockState(), c.getPoseStack())
      c.popPose()
    })

    renderer.setViewDistance(64)
    renderer.setInfiniteRenderBoundingBox()            // 可选：无限渲染范围
    return renderer
  })
})
```

### 渲染上下文（`setCustomRender` 的第二个参数）

| 字段/方法 | 说明 |
|---|---|
| `blockEntity` | 当前方块实体 |
| `blockEntityJS` | 若该方块实体来自 KubeJS（`KubeBlockEntity`），则为对应对象；否则 `null` |
| `partialTick` | 当前帧 partial tick |
| `poseStack` / `getPoseStack()` | 该方块实体的 pose（已平移到方块位置） |
| `submitNodeCollector` / `getSubmitNodeCollector()` | 几何提交器（一般不用直接操作） |
| `camera` | 相机渲染状态（`CameraRenderState`） |
| `packedLight` / `packedOverlay` / `getPackedLight()` / `getPackedOverlay()` | 光照与 overlay 值 |

上下文同样具备[世界渲染](世界渲染.md)的全部方法和 3D 变换方法。

### 渲染器上的常用设置

| 方法 | 说明 |
|---|---|
| `setCustomRender((renderer, context) => {})` | 设置每帧渲染回调 |
| `setViewDistance(distance)` | 可见距离（默认 64） |
| `setShouldRender((blockEntity, cameraPos) => boolean)` | 自定义可见性判断 |
| `setRenderBoundingBox(aabb)` | 自定义渲染包围盒 |
| `setInfiniteRenderBoundingBox()` | 无限包围盒（跨区块也能看到） |
| `setShouldRenderOffScreen(predicate)` | 离屏渲染判断（26.1.2 该接口无实体参数，目前仅记录） |

### 注意事项

1. `registerBlockEntityRender` 在**客户端渲染器注册阶段**触发，不是每帧；
2. 脚本重载（F3 + T）时该事件会以「无注册上下文」的形式再触发一次，用于把新的回调**热替换**到已注册的渲染器上；
3. 若脚本里注册的是此前从未注册过的方块实体类型，需要重载资源（F3 + T 或重进世界）后才会生效；
4. 纹理/模型资源变化后渲染器会自动重建，无需手动干预。
