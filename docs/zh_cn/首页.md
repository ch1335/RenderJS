# RenderJS 文档

RenderJS 是给 KubeJS 提供渲染能力的 Minecraft 附属模组。本目录是**中文用户文档**（脚本作者 / 整合包作者）。

English documentation: [`../en_us/Home.md`](../en_us/Home.md)

## 目录

| 文档 | 说明 |
|---|---|
| [快速开始](usage/快速开始.md) | 安装、脚本位置、颜色与常用对象、调试方法 |
| [事件](usage/事件.md) | `RenderJSEvents` 全部事件与触发时机 |
| [GUI 绘制](usage/GUI绘制.md) | HUD / Screen：文字、贴图、矩形、物品、2D 变换 |
| [世界渲染](usage/世界渲染.md) | 世界：方块、物品、几何体、选中框、相机坐标 |
| [实体与方块实体](usage/实体与方块实体.md) | 生物实体事件、方块实体渲染器 |
| [物品装饰](usage/物品装饰.md) | 物品图标角标的注册与绘制 |
