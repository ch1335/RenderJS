# RenderJS Documentation

RenderJS is a Minecraft addon that provides rendering capabilities for KubeJS. This folder contains the
**English user documentation** (for script authors and modpack makers).

Chinese documentation: [`../zh_cn/首页.md`](../zh_cn/首页.md)

## Contents

| Document | Description |
|---|---|
| [Getting Started](usage/getting-started.md) | Installation, script location, colors, common objects, debugging |
| [Events](usage/events.md) | All `RenderJSEvents` events and when they fire |
| [GUI Rendering](usage/gui.md) | HUD / Screen: text, textures, rectangles, items, 2D transforms |
| [World Rendering](usage/world.md) | Blocks, items, geometry, outlines and camera coordinates in the world |
| [Entities & Block Entities](usage/entity-and-block-entity.md) | Living entity events and block entity renderers |
| [Item Decorations](usage/item-decorations.md) | Registering and drawing overlays on item icons |
| [Global Bindings](usage/bindings.md) | Classes and constants available in scripts |
| [Upgrading from 1.21.1](usage/migration-1.21.1.md) | Migration checklist and breaking changes |
